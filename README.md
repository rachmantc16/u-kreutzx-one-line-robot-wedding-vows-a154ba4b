One line of wedding vows for a robot couple, at most 160 characters, and the line has to be funny. The program builds the vow from the classic ceremony skeleton — paired conditions, shared resources, and a "till death do us part" close — with every human term swapped for a machine one: glitches, updates, low batteries, chargers, bandwidth, and one very last backup.

## Run it

```sh
node main.ts
```

This writes the vow (exactly one line, no trailing newline) to `/output/entry.txt`.
